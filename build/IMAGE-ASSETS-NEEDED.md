# Image Assets Needed for SEO Optimization

## 📸 Required Images

To complete the SEO optimization, you need to create the following image files and place them in the `/public` folder:

### 1. Social Sharing Image (CRITICAL for SEO)
**File**: `og-image.png`
- **Size**: 1200 x 630 pixels
- **Format**: PNG or JPG
- **Purpose**: Shown when sharing on Facebook, LinkedIn, Twitter

**Content Suggestions**:
```
+------------------------------------------+
|                                          |
|  🏫 SchoolBerry                          |
|  NJ School Insights Dashboard            |
|                                          |
|  ✓ Compare Schools                       |
|  ✓ View Rankings                         |
|  ✓ Performance Data                      |
|  ✓ Demographics & Trends                 |
|                                          |
|  Bergen County & Beyond                  |
+------------------------------------------+
```

**Colors to use**:
- Purple: #7C3AED (brand color)
- White: #FFFFFF
- Light purple background: #F5F3FF

---

### 2. Favicon (Browser Tab Icon)
**File**: `favicon.ico`
- **Size**: 32 x 32 pixels
- **Format**: ICO
- **Design**: Simple "SB" letters or school icon

---

### 3. Android Icon (Small)
**File**: `icon-192.png`
- **Size**: 192 x 192 pixels
- **Format**: PNG
- **Design**: App icon with SchoolBerry logo

---

### 4. Android Icon (Large)
**File**: `icon-512.png`
- **Size**: 512 x 512 pixels
- **Format**: PNG
- **Design**: Same as icon-192.png but larger

---

### 5. Apple Touch Icon (iOS)
**File**: `apple-touch-icon.png`
- **Size**: 180 x 180 pixels
- **Format**: PNG
- **Design**: App icon for iOS devices

---

2. **Figma** (https://figma.com)
   - Professional design tool

3. **Favicon.io** (https://favicon.io)

### Desktop Tools:

## 📋 Quick Creation Guide

### For og-image.png (1200x630):
1. Open Canva or Figma
2. Create new design: 1200 x 630 px
3. Background: Light purple (#F5F3FF)
4. Add SchoolBerry logo or icon
5. Add text: "NJ School Insights Dashboard"
6. Add bullet points with key features
7. Export as PNG

### For Favicons:
1. Go to favicon.io
2. Choose "Text to Favicon"
3. Enter "SB" or school emoji "🏫"
4. Choose purple color (#7C3AED)
5. Download all sizes
6. Place in `/public` folder

## 💡 Pro Tips

1. Keep og-image.png file size under 1MB
2. Use high contrast for readability
3. Test on mobile devices
4. Keep text large and readable
5. Use brand colors consistently
6. Avoid too much text (people scroll fast)
7. Make it visually appealing

---

## ⚠️ Important Notes

- Images should be optimized for web (compress them)
- Use .png for icons and og-image (better quality)
- Test on different devices and browsers
- Update og-image.png when brand changes
- Cache-bust by updating filename if needed
